## 3. Tmall 精确商品对类目增量的算术贡献

Tmall 智能眼镜成交额从 Q1 的 6863.3 万元增至 Q2 的 8752.2 万元，净增 1888.8 万元。

精确商品查询均 `truncated=false`：

- ROKID 商品 `967433229862`：Q1 `q_9a09699d`；Q2 `q_9b0bed3d`
- 夸克 S1 原商品 ID `972640809714`：Q1 `q_9f233069`；Q2 `q_bafdcdb3`
- 夸克 S1 新商品 ID `1035065479567`：Q1 `q_2a383c13`（无返回值）；Q2 `q_9c3a87fc`
- 华为新品商品 ID `1040635263498`：Q1 `q_dbb19f7f`（无返回值）；Q2 `q_6025b42c`

| 商品结构 | Q1 成交额 | Q2 成交额 | 对类目净增的算术贡献 |
| --- | ---: | ---: | ---: |
| ROKID 单一商品 ID | 1643.7 万元 | 2318.0 万元 | +674.3 万元，35.7% |
| 两个标题均指向 S1 的夸克商品 ID 合计 | 2109.6 万元 | 2263.9 万元 | +154.3 万元，8.2% |
| 华为新商品 ID | 无返回值 | 447.8 万元 | +447.8 万元，23.7% |

以上三组可识别商品结构合计解释 Tmall 类目净增的 67.6%。这是商品 ID 层面的算术归因，不是因果归因，也不是三个品牌的完整贡献。夸克两条商品 ID 的合并依据是标题均明确标注 S1，应保留“已识别 S1 商品 ID”口径，不能外推到全部 S1 链接。

额外观察：ROKID 该商品 Q2 成交额增长 41.0%、销量增长 52.7%、ASP 下降 7.6%；夸克原 S1 商品 ID 成交额下降 53.9%，但新 S1 商品 ID 在 Q2 新增 1291.7 万元。只看旧链接会把商品迁移误判成需求崩塌，只看新链接又会把迁移误判成纯新增。

## 4. 当前属性数据缺口

公开数据合同声明 `specification` 可在明细查询中返回，但本轮 JD、Tmall `query_details` 均返回 `semantic_contract_unavailable`，因此没有把规格 JSON 当作证据写入文章。当前属性判断只使用：

1. Asklear 商品标题样本；
2. 精确商品的成交额、销量与 ASP；
3. 厂商官方产品页对显示、相机、重量和功能的说明。

后续统一字段合同恢复后，优先补查重量、显示方案、镜片类型、续航、颜色/框型等规格字段，再进行全量属性渗透率和属性贡献分析。
