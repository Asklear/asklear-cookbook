# Recipes

一个 Recipe 对应一项完整商业研究任务，最终交付 PPT、PDF 或 Dashboard，而不是一次工具调用。

打开一个 Recipe，查看结果预览，然后复制其中的“Use with your Agent”指令即可开始。

## Add a recipe

复制 [`_template/`](_template/)，使用小写连字符命名目录，并保持 `status: draft`。只有真实运行结果和交付物齐备后才能改为 `verified`。
