# AI 眼镜示例

这是一次真实运行，验证 2026 年上半年 AI 眼镜的市场热度是否已转化为零售成交。

- 数据范围：2026-01 至 2026-06；
- 平台：京东、天猫，分别查询；
- 核心代理：两平台原始三级类目“智能眼镜”；
- 交付物：[HTML](report.html) / [PDF](report.pdf)；
- 核心证据：[data.json](data.json) / [review.json](review.json)；
- 商品下钻：[drilldown.md](drilldown.md)。
- 复核对应原稿：[reviewed-research.md](reviewed-research.md)；
- 运行与交付物版本：[run.json](run.json)。

结论只达到“早期成交”：两个平台都出现增长，但品牌和商品集中度高，尚无激活、留存和持续佩戴证据。

`review.json` 覆盖核心 Asklear 事实和 `reviewed-research.md`；最终报告是编辑型衍生稿，商品级延伸保存在下钻记录中，外部资料由报告直接链接原始页面。
