05

结论与行动建议

四条可落地的方向。
  1. 京东：乘胜追击，但守住价格心智。份额势能正盛，可继续加注货盘与流量；同时监控降价对品牌溢价的侵蚀，避免把"品质旅行枕"打成"性价比枕"。直接对手是平台自有京造，盯其价格与货盘节奏。
  2. 天猫：守成也要投入。份额虽稳，但高端带（MUJI +81%、松伴翻倍）正在升温，"稳态"需靠爆款迭代（经典款 + 第三代）与 IP/内容维持，切忌躺平。
  3. 向上卡位 ¥340+ 白点，宜早不宜迟。超高端仅松伴一家且半年翻倍，证明需求真实（靠功能创新而非 IP）。睡洞有品牌力向上延伸，窗口正在收窄。
  4. 差异化探索：母婴人群 + 降噪卖点 + IP 联名。儿童/母婴是头部空白（待验证）；降噪能撑 ¥150+ 溢价（京东已验证）；IP 联名是高价带流量抓手（野兽派靠一款做到品类第 4）。可小步试水。
